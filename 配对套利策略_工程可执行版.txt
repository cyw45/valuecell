一、策略原理与经济模型
═════════════════════════════════════════════════════════════

──────────────────────────────────────
1.1 核心逻辑
──────────────────────────────────────

  跟踪两币价格比值(A/B)的Z-score，当比值偏离均值时买入被低估
  的那个币，等比值回归后平仓获利。

  比值 = 价格A / 价格B
  Z-score = (当前比值 - 滚动均值) / 滚动标准差

  ┌────────────────┬────────────────────────────────────────────────┐
  │ Z > 2.0       │ A相对B高估 → 买入B（B被低估，等比值回落）       │
  │ Z < -2.0      │ B相对A高估 → 买入A（A被低估，等比值回升）       │
  │ Z回归到±0.5   │ 比值回归 → 平仓止盈                             │
  │ Z超过±4.0     │ 关系破裂 → 止损平仓                           │
  │ 持仓超180根   │ 超时未回归 → 时间止损                         │
  └──────────────┴────────────────────────────────────────────────┘

──────────────────────────────────────
1.2 经济模型——单腿轮换（非双腿对冲）
──────────────────────────────────────

  本策略为单腿轮换策略，不是传统双腿市场中性对冲。

  单腿轮换定义：
    - Z > 2.0时只买入B（不卖出A）
    - 持B等到Z回归到0.5时卖出B止盈
    - 如果Z再次偏离到-2.0以下，卖出B后买入A
    - 始终只持有A或B中的一个，不同时持有两个

  与双腿对冲的区别：
  ┌──────────────┬──────────────────────────────────────────────────┐
  │ 双腿对冲     │ 同时买入A卖出B（或反过来），市场中性             │
  │ 单腿轮换     │ 只买入被低估的那个，赌比值回归，非市场中性       │
  └──────────────┴──────────────────────────────────────────────────┘

  单腿轮换的优势：
    - 资金效率高（100U只买一个币，不需要200U做双腿）
    - 操作简单（不需要借币做空，纯现货买入卖出）
    - 适合现货账户（不做空、不借币、不合约）

  单腿轮换的风险：
    - 非市场中性，大盘系统性下跌时持仓会亏
    - 比值发散时（Z>4）止损，单腿亏损不因对冲抵消

五、执行流程
═════════════════════════════════════════════════════════════

  1. 初始化
     - 加载6个币对的4h K线数据（12个币种）
     - 对每个币对计算比值序列、240根滚动均值、滚动标准差、Z-score
     - 相关性矩阵计算：240根窗口皮尔逊相关系数，不足240根跳过

  2. 每根4h K线收盘时
     对每个币对执行：
     a. 更新比值的滚动均值和标准差
     b. 计算当前Z-score
     c. 如果无持仓：
        - Z > 2.0 → 买入B（A被高估，B被低估）
        - Z < -2.0 → 买入A（B被高估，A被低估）
     d. 如果持仓：
        - 持B时 Z ≤ 0.5 → 卖B止盈
        - 持B时 Z ≥ 4.0 → 卖B止损（关系破裂）
        - 持A时 Z ≥ -0.5 → 卖A止盈
        - 持A时 Z ≤ -4.0 → 卖A止损（关系破裂）
        - 持仓超180根 → 无论盈亏平仓
     e. 记录交易

  3. 60秒轮询（止损专用）
     - 检查所有持仓的Z-score是否达到止损线(±4.0)
     - 达到则市价平仓，不等4h收盘

  4. 信号冲突处理
     - 同一币对同一时刻只有一个方向信号
     - 不同币对之间独立运行
     - 12个币种互不重叠，不存在仓位冲突


═════════════════════════════════════════════════════════════
六、订单生命周期
═════════════════════════════════════════════════════════════

  下单：
    类型：市价单（type=market, time_in_force=ioc）
    买入：amount = USDT金额（Gate.io市价买单用quote货币金额）
    卖出：amount = 基础币数量（精度8位小数）

  等待成交：
    下单后每1秒轮询订单状态，最多等10秒
    status=closed → 确认成交
    status=cancelled → 已取消
    超时(10秒) → 撤销未成交部分

  成交量计算：
    Gate.io v4返回字段：amount=原始请求量, left=剩余量, filled_total=成交USDT, avg_price=成交均价
    实际成交量(币) = filled_total / avg_price（当avg_price > 0时）
    实际成交量(币) = amount - left（当avg_price = 0时）
    不得用原始amount字段判断成交量

  部分成交处理：
    记录实际成交量，更新持仓数量
    未成交部分撤销

  重试：
    最多3次，每次间隔5秒
    3次失败后放弃入场，不影响其他币对

  翻转处理：
    从持B翻转为持A时：先卖B（确认成交）→ 再买A（确认成交）
    两步串行，不并行
    如果卖B成功但买A失败，记录异常，下个4h收盘重试买A

七、状态持久化与启动对账
═════════════════════════════════════════════════════════════

  状态文件：配对套利_state.json
  内容：
    positions:  当前持仓 {pair: {side, coin, entry, amount, entry_ts, kline_idx}}

    1) 查询Gate.io现货余额 GET /api/v4/spot/accounts
    2) 对比state文件中的持仓
    3) state有持仓但交易所余额为0 → 标记已平仓，删除持仓
    4) 交易所有余额但state无持仓 → 警告，需人工确认
    5) 不一致项写入日志
  可用 --reconcile-only 参数仅对账后退出

八、API层规格
═════════════════════════════════════════════════════════════

  交易所：Gate.io（实盘+回测统一数据源，不再跨交易所）

  限频保护：

    429限频响应：自动等待5秒后重试

  断线处理：
    捕获ConnectionError，等待60秒重连
    最多重试3次，3次失败后进入安全模式（只检查止损，不开新仓）

  Gate.io接口：
    K线：GET /api/v4/spot/candlesticks（4h K线）
    行情：GET /api/v4/spot/tickers（最新价）
    下单：POST /api/v4/spot/orders（市价 type=market, time_in_force=ioc）
    查单：GET /api/v4/spot/orders/{id}（filled_total, avg_price, left）
    撤单：DELETE /api/v4/spot/orders/{id}
    账户：GET /api/v4/spot/accounts（余额查询）
    签名：HMAC-SHA512，Header: KEY, SIGN, Timestamp

  交易对精度：从 /api/v4/spot/currency_pairs 获取price_precision和amount_precision

九、风险控制
═════════════════════════════════════════════════════════════

  1. 比值发散止损（Z ≥ 4.0）
     当两币比值偏离4个标准差，说明相对关系已破裂（如某币生态爆发、
     另一币原地踏步），立即平仓不恋战。这是最重要的风控线。
     回测中32%的交易触发此止损，单笔平均亏损-1.65U，可控。
     60秒轮询检查，不等4h收盘。

  2. 时间止损（180根 = 7.5天）
     比值既不回归也不发散，持仓超7.5天强制平仓，释放仓位给新信号。
     回测中8%的交易触发此止损。

  3. 币对互不重叠
     6对涉及12个独立币种，单一币种风险不超过100U。

  4. 单对最大回撤
     回测中最大个体回撤：DOGE/PEPE 143.8U，ADA/DOGE 136.3U。
     单对最大回撤超过150U时暂停该对，检查相关性是否已变化。
