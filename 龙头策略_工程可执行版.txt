全自动现货龙头策略 · 工程可执行版

文档性质：工程可执行规格书（可直接用于程序开发与部署）
策略类型：加密货币现货量化交易策略
交易方向：现货做多
适用交易所：Gate.io（实盘 + 回测数据源统一，不再跨交易所）
K线周期：4h（策略为此周期设计，不得更改）

候选池规模：40币（按24h成交额实时取前40，自动排除稳定币/杠杆代币/代币化股票/非ASCII代币）
最大同时持仓：6单
单笔买入金额：100 USDT（新币降为50 USDT）
最大理论总仓位：600 USDT

免责声明：
本策略仅用于量化交易逻辑设计、程序开发、历史回测、模拟盘和风险管理研究，不构成任何投资建议。
加密货币市场具有极高波动性、流动性风险、交易所风险、API风险和极端行情风险。
正式实盘前必须经过历史回测、模拟盘测试以及充分的小资金验证。

═════════════════════════════════════════════════════════════
三、核心策略模块
═════════════════════════════════════════════════════════════

──────────────────────────────────────
模块0：事件驱动模型
──────────────────────────────────────

系统由以下事件驱动，每个事件有明确的触发条件和处理流程：

  事件1 — 4h K线收盘事件（主驱动）
    触发：检测到新的4h K线时间戳（UTC 0/4/8/12/16/20整点）
    处理：信号扫描 → 入场决策 → 出场决策（非止损类）
    优先级：中

  事件2 — 60秒轮询事件（止损专用）
    触发：每60秒定时器
    处理：检查所有持仓的止损线和移动止损线
    优先级：最高（可中断4h收盘事件的处理）

  事件3 — 订单成交事件
    触发：下单后轮询订单状态变化
    处理：确认成交量 → 更新持仓状态 → 保存state
    优先级：高

  事件4 — 利润保护确认事件
    触发：浮盈达+4%时启动45秒计时器
    处理：计时器到期后检查是否保持+3.5%以上
      保持 → 激活移动止损（PENDING → ACTIVE）
      跌破 → 取消保护（PENDING → None）
    优先级：中

  事件冲突处理：
    止损事件(事件2)优先于一切，可中断其他事件
    4h收盘事件(事件1)和利润保护确认事件(事件4)按时间顺序处理
    订单成交事件(事件3)立即处理，不等待

──────────────────────────────────────
模块1：系统状态机
──────────────────────────────────────

持仓状态机：
  IDLE → ECS评分通过 + 入场条件满足 → PENDING(已下单)
  PENDING → 成交确认 → HOLDING(持仓中)
  HOLDING → 触发止损/熔断/移动止损/EDE退出 → CLOSED(已平仓)
  HOLDING → 浮盈达+4% → PENDING_PROTECT(利润保护待确认, 45秒计时)
  PENDING_PROTECT → 保持45秒不跌破+3.5% → ACTIVE(利润保护激活)
  PENDING_PROTECT → 跌破+3.5% → HOLDING(保护取消)
  ACTIVE → 移动止损/EDE退出 → CLOSED

系统级状态：
  RUNNING   正常运行
  PAUSED    连亏暂停（连续8笔亏损后暂停48小时）
  IDLE      无持仓且无候选

──────────────────────────────────────
模块2：数据质量控制与候选池
──────────────────────────────────────

K线数据要求：
  周期：4h
  字段：ts, open, high, low, close, volume, quote_vol
  最小数据量：60根（不足则跳过该币种）
  数据源：Gate.io（实盘+回测统一数据源，不再跨交易所）
  K线时间戳对齐：UTC 4h整点（0/4/8/12/16/20）
  缓存：本地 data_cache/ 目录，重复请求走缓存

候选池构建：
  规模：40币（MAX_TOP_N=40）
  来源：Gate.io 现货 USDT 交易对，按24h成交额取前40
  构建时机：每4h K线收盘时重建
  自动排除：
    - 稳定币（USDT/USDC/FDUSD/TUSD/DAI/BUSD/USDD/USD1/PYUSD/GUSD/LUSD/XAUT/PAXG）
    - 杠杆代币（3L/3S/5L/5S/2L/2S 后缀）
    - 代币化股票（NVDAG/TSLAG/QQQG/AMDG/SPYG 等以G结尾，NVDAX/TSLAX 等）
    - 非ASCII代币（中文名代币）
  上市时间获取：Gate.io /api/v4/spot/currency_pairs 接口
  新币处理：上市晚的币自动探测最早K线（二分法），按各自上市日起参与

──────────────────────────────────────
模块3：候选币筛选流程
──────────────────────────────────────

每根4h K线推送到时，对40币池执行以下筛选：

  1) 流动性过滤：24h成交额折算 >= LIQUIDITY_MIN(200000 USDT)
  2) 相对强度过滤：近6根（24h）涨幅 >= RS_WIN_REQ(4%)
  3) 数据充分性：当前K线索引 >= BREAKOUT_LOOKBACK + 3（需至少23根历史）

通过筛选的币种进入入场扫描（模块5）。
注意：40币池是候选宇宙，实际能通过筛选的通常只有5-15个/根。

──────────────────────────────────────
模块4：BTC趋势过滤与斜率门控
──────────────────────────────────────

两层BTC门控，均须通过才开新仓：

  第一层——BTC趋势门控（基础）：
    条件1：BTC 4h EMA21 > EMA55（均线多头排列）
    条件2：非连续3根阴线（短期无急跌）
    两条件同时满足才允许开新仓

  第二层——BTC斜率过滤（因子5）：
    条件：BTC EMA55 近12根（48h）持续上行
    实现：当前EMA55 > 12根前的EMA55
    作用：大周期下行趋势中停止开仓

  注意：已有持仓不受BTC门控限制（可正常触发止损/止盈/移动止损），
  只限制新开仓。

──────────────────────────────────────
模块5：入场系统——双路径确认
──────────────────────────────────────

通过模块3筛选 + 模块4门控的币种，执行双路径入场扫描：

  ECS（入场信心分）计算公式：
    ECS = 流动性分 + 相对强度分 + 突破分 + 量能分 + 趋势分

    流动性分：24h成交额≥200000 → 1分，否则0分（不过滤）
    相对强度分：近6根涨幅 × 5，上限20分
    突破分：Path A(创20周期新高+放量) → 5分；Path B(回踩) → 2分
    量能分：vol/vol_ma20 ≥ 1.5 → 10分；≥ 1.0 → 5分；否则0分
    趋势分：EMA21 > EMA55 → 10分；否则0分

    入场门槛：ECS ≥ 48分

  Path A——突破确认：
    条件1：收盘价创20周期新高（close > max(high[idx-20:idx])）
    条件2：量能放大（volume > vol_ma20 × 1.5）
    条件3（因子6）：币自身 EMA21 > EMA55（逆势突破不追）
    评分：48 + 5 + 量能分 + 趋势分 = 53~63分

  Path B——回踩确认：
    条件1：近15根内存在符合Path A条件1(创20周期新高)+条件2(放量)的历史K线
    规则冻结：取近15根内最新的符合Path A条件1+2的K线，该K线收盘价为回踩基准
    条件2：当前收盘价 ≥ 回踩基准收盘价 × (1 - 0.02)
    评分：48 + 2 + 量能分 + 趋势分 = 50~60分

  候选排序：按ECS评分降序，逐个尝试入场，直到持仓满6单或候选耗尽。
  同一币种已有持仓则跳过；冷却期内则跳过。

──────────────────────────────────────
模块6：仓位管理
──────────────────────────────────────

  单笔仓位：
    默认：ORDER_AMOUNT(100 USDT)
    新币降仓：上市<30天 → NEW_COIN_AMOUNT(50 USDT)
    新币禁入：上市<7天 → 不参与交易
    上市时间判定：从Gate.io /api/v4/spot/currency_pairs获取交易对创建时间
  入场成本：cost = amount × (1 + slip_entry(0.15%) + spread(0.05%))
  入场数量：qty = amount / price
  最大同时持仓：MAX_POSITIONS(6)，达到后不再开新仓
  分批平仓：支持部分平仓（分批止盈、EDE警告减仓），剩余仓位继续管理
  持仓对象字段：sym, entry_ts, entry_price, qty, cost, peak, path, score,
                protect, protect_ts, partial_done, new_coin_flag

──────────────────────────────────────
模块7：止损系统
──────────────────────────────────────

  出场优先级（从高到低，同一时刻多条件触发时执行最高优先级）：
    1. 8%硬止损（60秒轮询，最高优先级）
    2. 弱势早退（36h/-2.5%，4h收盘检查）
    3. 7日亏损熔断（168h/未达+5%，4h收盘检查）
    4. 移动止损（利润保护激活后，60秒轮询）
    5. 分批止盈（+8%触发，4h收盘检查）
    6. EDE退出（EDS<35强平或EDS<50警告减仓，4h收盘检查）

  7.1 8% 硬止损（不可关闭）：
    条件：当前价 <= 入场价 × (1 - 0.08)
    执行：60秒轮询检查，触发后市价全额平仓
    平仓后：进入亏损冷却（24小时）
    不使用stop-limit条件单，不使用5分钟插针确认（均已被回测否证）

  7.2 7日亏损熔断：
    条件：持仓时间 >= 168小时(7天) 且 当前价 < 入场价 × (1 + 0.05)
    执行：全额平仓（未达+5%利润的仓位7天后强平，释放资金）
    平仓后：进入亏损冷却（24小时）

  7.3 弱势早退（因子1）：
    条件：持仓时间 >= 36小时 且 当前价 < 入场价 × (1 - 0.025)
    执行：全额平仓（不等7日熔断，提前截断阴跌磨损仓）
    平仓后：进入亏损冷却（24小时）

──────────────────────────────────────
模块8：止盈系统——利润保护状态机
──────────────────────────────────────

  利润保护触发（因子2）：
    触发条件：当前价 >= 入场价 × (1 + 0.04)
    状态流转：
      None → 浮盈达+4% → PENDING（启动45秒计时器）
      PENDING → 保持45秒且不跌破+3.5% → ACTIVE（激活移动止损）
      PENDING → 45秒内跌破+3.5% → None（取消，回退到普通持仓管理）
    计时器由事件4（利润保护确认事件）驱动

  分批止盈（因子3）：
    触发条件：峰值价 >= 入场价 × (1 + 0.08)
    执行：市价平仓34%仓位，落袋为安
    滑点：止盈滑点 slip_exit(0.25%)
    触发后标记 partial_done=True，不再重复触发

──────────────────────────────────────
模块9：移动止损阶梯
──────────────────────────────────────

利润保护激活(ACTIVE)后，根据峰值价/入场价比值锁定移动止损线：

  峰值/入场价 ≥    止损线（×入场价）
  1.05              1.03（保底+3%）
  1.08              1.04
  1.12              1.07
  1.15              1.10
  1.25              1.15
  1.40              1.25
  1.60              1.40
  2.00              1.60
  3.00              2.50
  4.00              3.50

峰值/入场价 < 1.05时止损线 = 入场价 × 0.97（保底-3%止损）。
移动止损由60秒轮询事件检查。当前价跌至止损线时市价全额平仓，止盈滑点 slip_exit(0.25%)。
平仓后进入盈利冷却（12小时）。

──────────────────────────────────────
模块10：离场决策引擎（EDE）
──────────────────────────────────────

  10.1 EDS（离场决策分）= 趋势分 + RSI分 + 量能分，上限100。未激活利润保护时 ×0.9。

  趋势分（取最高匹配档）：
    输入：当前4h收盘价、EMA21、EMA55
    price > EMA21 > EMA55    → 30分（完美多头排列）
    price > EMA21            → 20分
    price > EMA55             → 12分

  RSI分（取最高匹配档）：
    输入：14周期RSI（Wilder计算法）
    70 ≤ RSI ≤ 90            → 25分（强势不超买）
    RSI ≥ 55                 → 18分
    RSI ≥ 45                 → 10分

  量能分（取最高匹配档）：
    输入：当前4h成交量、20周期均量
    vol / vol_ma20 ≥ 1.5     → 25分（放量）
    vol / vol_ma20 ≥ 1.0     → 12分（正常量）

  计算频率：每根4h K线收盘时计算一次。

  10.2 EDE决策表

  利润保护已激活(ACTIVE)时：
    EDS ≥ 80    → STRONG_HOLD（强持）
    EDS < 35    → STRONG_EXIT（强平——全额平仓）
    35 ≤ EDS < 50 → EXIT（退出——全额平仓）
    EDS ≥ 50    → HOLD（持有）

  利润保护未激活时：
    EDS < 50    → CAUTION（警告——平仓35%）
    EDS ≥ 50    → HOLD（持有）

  10.3 EDE减仓规则
    CAUTION减仓35%：减仓数量 = 持仓数量 × 0.35

    status=closed → 确认成交

    超时(10秒) → 撤销未成交部分

    Gate.io v4返回字段：amount=原始请求量, left=剩余量, filled_total=成交USDT总额, avg_price=成交均价
    实际成交量(币) = filled_total / avg_price（当avg_price > 0时）
    实际成交量(币) = amount - left（当avg_price = 0时）
    不得用原始amount字段判断成交量

  部分成交处理：
    记录实际成交量，更新持仓数量
    未成交部分撤销

  重试：
    最多3次，每次间隔5秒
    3次失败后放弃入场，不影响其他币种
