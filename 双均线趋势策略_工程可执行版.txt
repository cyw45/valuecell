双均线趋势跟踪策略 · 工程可执行版

文档性质：工程可执行规格书（可直接用于程序开发与部署）
策略类型：加密货币现货量化交易策略
交易方向：现货做多 + 杠杆现货做空
适用交易所：Gate.io（现货 + 杠杆现货借币做空）
K线周期：4h（策略为此周期设计，不得更改）
部署脚本：ma_cross_live.py（Gate.io API + 信号 + 下单 + 止损 + 做空借币全流程）

候选池规模：41币（回测全池，固定列表）
最大同时持仓：6单
单笔买入金额：100 USDT
最大理论总仓位：600 USDT

免责声明：
本策略仅用于量化交易逻辑设计、程序开发、历史回测、模拟盘和风险管理研究，不构成任何投资建议。
加密货币市场具有极高波动性、流动性风险、交易所风险、API风险和极端行情风险。
正式实盘前必须经过历史回测、模拟盘测试以及充分的小资金验证。

二、策略核心逻辑
═════════════════════════════════════════════════════════════

──────────────────────────────────────
2.1 趋势判定（金叉/死叉）
──────────────────────────────────────
  金叉（MA10 > MA20）= 多头行情
  死叉（MA10 < MA20）= 空头行情
  MA使用简单移动平均（SMA），非EMA

──────────────────────────────────────
2.2 入场信号（价格穿越MA10）
──────────────────────────────────────
  多头行情 + 价格上穿MA10 → 做多
  空头行情 + 价格下穿MA10 → 做空

  上穿定义：前一根收盘价 ≤ 前一根MA10 且 当前收盘价 > 当前MA10
  下穿定义：前一根收盘价 ≥ 前一根MA10 且 当前收盘价 < 当前MA10

  信号在4h K线收盘时检查，确认后在下一时刻执行（市价下单）。

──────────────────────────────────────
2.3 出场条件（优先级：止损 > 超时 > 信号出场）
──────────────────────────────────────
  条件1 — 止损出场（最高优先级）：浮亏达5%
    多头：当前价 ≤ 入场价 × (1 - 5%)
    空头：当前价 ≥ 入场价 × (1 + 5%)
    止损实时检查（每60秒轮询），不等4h收盘

  条件3 — 超时出场：持仓超过168小时（7天）
    到时无论盈亏强制平仓

──────────────────────────────────────
2.4 冷却规则
──────────────────────────────────────
  平仓后该币种冷却12小时，期间不开新仓
  冷却时间记录在 state 文件中

═════════════════════════════════════════════════════════════
四、核心策略模块
═════════════════════════════════════════════════════════════

以下模块均在 ma_cross_live.py 中实现，参数与代码逐项验证一致。

──────────────────────────────────────
模块1：Gate.io API 封装
──────────────────────────────────────
  签名：HMAC-SHA512（Gate.io v4标准）
  公开接口（无需认证）：
    GET /api/v4/spot/candlesticks  拉取K线
    GET /api/v4/spot/tickers       获取最新价
  认证接口（需要API Key）：
    GET /api/v4/spot/accounts             查询余额
    POST /api/v4/spot/orders              下单
    GET /api/v4/spot/orders/{id}          查询订单
    DELETE /api/v4/spot/orders/{id}       撤单
    POST /api/v4/spot/margin/loans        借币（做空）
    POST /api/v4/spot/margin/loans/{id}/repay  还币（平空）
    GET /api/v4/spot/margin/loans         查询借币

  API Key/Secret 通过环境变量注入：
    export GATE_API_KEY="你的key"
    export GATE_API_SECRET="你的secret"

──────────────────────────────────────
模块2：K线数据获取
──────────────────────────────────────
  数据源：Gate.io 现货 4h K线
  单次拉取：200根（KLINE_LIMIT=200）
  字段：ts, open, high, low, close, volume
  返回：时间正序排列（旧→新）
  最少需要 MA_SLOW + 2 = 22 根才可计算信号

──────────────────────────────────────
模块3：均线计算
──────────────────────────────────────
  方法：简单移动平均（SMA）
  快线：MA_FAST = SMA(close, 10)
  慢线：MA_SLOW = SMA(close, 20)
  计算窗口：前 period-1 根为 None，从第 period 根开始有值

──────────────────────────────────────
模块4：信号生成
──────────────────────────────────────
  每根4h K线收盘时执行一次信号扫描：
    1) 计算当前MA10、MA20、前一根MA10
    2) 判定趋势：MA10 > MA20 = 多头，MA10 < MA20 = 空头
    3) 检测穿越：
       上穿 = 前收 ≤ 前MA10 且 当前收 > 当前MA10
       下穿 = 前收 ≥ 前MA10 且 当前收 < 当前MA10
    4) 入场规则：
       多头 + 上穿 → 做多
       空头 + 下穿 → 做空

  信号判定与回测引擎 ma_cross_trend.py 完全一致

──────────────────────────────────────
模块5：做多执行（现货买入）
──────────────────────────────────────
  入场：
    1) place_market_buy(symbol, 100) 市价买入100 USDT
    2) wait_order_fill 等待成交确认（最多10秒，超时取消）
    3) 从 get_order_filled 获取实际成交量(filled_coin)和均价(avg_price)
    4) 确认成交后记录入场价、数量、时间戳，保存state
    5) 未成交则放弃入场，不影响持仓
  出场：
    1) place_market_sell(symbol, 持仓数量) 市价卖出全部持仓币
    2) wait_order_fill 等待成交确认
    3) 未成交则保留持仓，下一轮重试（不删除持仓记录）
    4) 成交后计算盈亏：(exit/entry - 1 - 0.007) × 100

──────────────────────────────────────
模块6：做空执行（杠杆现货借币）
──────────────────────────────────────
  前提：Gate.io 杠杆现货账户已开通，有借币权限
  入场：
    1) margin_borrow(借入基础币, 数量 = 100U / 当前价)
    2) place_market_sell 市价卖出借来的币
    3) wait_order_fill 确认成交，获取实际卖出量(filled_coin)和均价
    4) 借币失败或卖单未成交 → 还币后放弃
    5) 记录入场价、实际卖出量、loan_id、时间戳
  出场：
    1) 估算买入USDT = 借币数量 × 当前价 × 1.02（2%滑点缓冲）
    2) place_market_buy 市价买入
    3) wait_order_fill 确认成交，获取实际买入量(filled_coin)
    4) margin_repay 还实际买入数量，loan_id非空才还
    5) 买入量 < 借入量 → 记录欠币，后续补买
    6) 计算盈亏：-(exit/entry - 1) × 100 - 0.007 × 100

  注意：借币有利息（Gate.io约0.02%/天），168h最大持仓约1.4%利息成本
  实际盈亏需扣除借币利息，回测未计入此项

──────────────────────────────────────
模块7：订单成交确认（wait_order_fill）
──────────────────────────────────────
  功能：下单后轮询订单状态，确认成交或超时取消
  流程：
    1) 每1秒查询 get_order_filled(symbol, order_id)
    2) status=closed → 返回成交结果
    3) status=cancelled → 返回已取消结果
    4) 超时(10秒) → 撤销未成交部分，返回最终结果
  成交量计算：
    Gate.io v4: amount=原始请求量, left=剩余量, filled_total=成交USDT
    filled_coin = filled_total / avg_price（市价买单）
    filled_coin = amount - left（市价卖单）
  原始请求量(amount)不等于成交量，不得用于判断成交

──────────────────────────────────────
模块8：止损管理
──────────────────────────────────────
  触发条件：
    多头：当前价 ≤ 入场价 × (1 - 5%)
    空头：当前价 ≥ 入场价 × (1 + 5%)
  检查频率：每60秒轮询（不等4h收盘）
  执行方式：市价平仓 + 成交确认

──────────────────────────────────────
模块9：超时管理
──────────────────────────────────────
  最大持仓：168小时（7天 = 42根4h K线）
  到时强制平仓，无论盈亏
  防止长期持仓占用仓位名额

──────────────────────────────────────
模块10：冷却规则
──────────────────────────────────────
  平仓后该币种冷却12小时
  冷却期内不开放该币种的新仓位
  冷却状态持久化到 state 文件

──────────────────────────────────────
模块11：状态持久化（原子写入）
──────────────────────────────────────
  状态文件：ma_cross_state.json
  内容：
    positions:  当前持仓 {symbol: {side, entry, amount, entry_ts, kline_ts}}
    cooldowns:  冷却记录 {symbol: 到期时间戳}
    loans:      借币记录 {symbol: loan_id}
  写入方式：先写临时文件，成功后 os.replace 原子覆盖，防止崩溃损坏
  每次下单、平仓、扫描后自动保存
  程序重启后自动恢复

──────────────────────────────────────
模块12：启动对账（reconcile）
──────────────────────────────────────
  实盘启动时自动执行：
    1) 查询现货余额 get_balances
    2) 查询未还借币 get_open_loans
    3) 多头持仓: state有记录但交易所余额为0 → 标记已平仓，删除持仓
    4) 空头持仓: state有借币但交易所无未还记录 → 标记已平仓，删除持仓
    5) 不一致项写入日志，需要人工确认
  目的：防止程序崩溃后state与交易所实际持仓不一致
  可用 --reconcile-only 参数仅对账后退出

──────────────────────────────────────
模块13：限频保护
──────────────────────────────────────
  API请求最小间隔：0.15秒（API_INTERVAL）
  429限频响应：自动等待5秒后重试
  网络断开：捕获ConnectionError，等待60秒重试
  目的：41币轮询不会触发Gate.io限频

五、部署步骤
═════════════════════════════════════════════════════════════

──────────────────────────────────────
5.1 环境准备
──────────────────────────────────────
  1) Python 3.8+
  2) 安装依赖：
     pip install requests
  3) 注册 Gate.io 账户
  4) 创建 API Key（需要现货交易权限；做空需要杠杆现货权限）
  5) 设置环境变量：
     export GATE_API_KEY="你的key"
     export GATE_API_SECRET="你的secret"

──────────────────────────────────────
5.2 杠杆现货账户开通（做空必需）
──────────────────────────────────────
  1) Gate.io → 现货 → 杠杆 → 开通杠杆账户
  2) 划转部分USDT到杠杆账户（建议600U）
  3) 确认借币权限已开通
  4) 如不开通做空，启动时加 --no-short 参数（仅做多，回测显示会亏损）

──────────────────────────────────────
5.3 模拟盘运行
──────────────────────────────────────
  python ma_cross_live.py

  模拟盘不下真实订单，只记录信号和模拟盈亏
  建议运行 ≥ 1 个月，对比模拟结果与回测预期

──────────────────────────────────────
5.4 实盘运行
──────────────────────────────────────
  python ma_cross_live.py --live

  实盘会真实下单。建议先用小资金（如单笔10U）验证：
    修改 ORDER_AMOUNT = 10
  验证无误后恢复 100U 正式运行

──────────────────────────────────────
5.5 常用参数
──────────────────────────────────────
  --live        实盘模式
  --no-short    禁用做空（仅做多）
  --no-long     禁用做多
  --once        只扫描一次（测试用）

──────────────────────────────────────
5.6 守护进程（推荐）
──────────────────────────────────────
  使用 systemd 或 nohup 保持后台运行：

  nohup python3 ma_cross_live.py --live > /dev/null 2>&1 &

  或 systemd service:
  [Unit]
  Description=MA Cross Strategy
  After=network.target

  [Service]
  Type=simple
  WorkingDirectory=/path/to/ma_strategy
  Environment=GATE_API_KEY=你的key
  Environment=GATE_API_SECRET=你的secret
  ExecStart=/usr/bin/python3 /path/to/ma_strategy/ma_cross_live.py --live
  Restart=always
  RestartSec=60

  [Install]
  WantedBy=multi-user.target

七、风险提示
═════════════════════════════════════════════════════════════

1) 做空需借币，借币有利息成本（约0.02%/天），回测未计入
2) 止损用4h收盘价检查在实盘改为60秒轮询，但极端行情（闪崩）仍可能滑点
3) 市价单有滑点，实盘建议观察成交均价与预期的偏差
4) 21%胜率意味着约80%的交易会亏损，需承受连续亏损的心理压力
5) 42%最大回撤意味着600U总仓位可能浮亏至约252U
6) API Key 泄露可能导致资金损失，务必妥善保管
7) 交易所可能宕机、API限流、网络中断，需有容错处理
8) 加密货币存在极端行情（如单日跌50%+），止损可能严重滑点

建议部署顺序：模拟盘1月 → 小资金实盘2周 → 正式运行
